# ZETA BARBER

Sitio estático HTML, CSS y JavaScript listo para abrir en Visual Studio Code y desplegar en Vercel.

## Archivos
- `index.html`: estructura y formulario de WhatsApp.
- `style.css`: estilos visuales y responsive.

## Probar localmente
Abrí la carpeta en VS Code y ejecutá `index.html` con la extensión Live Server, o abrí el archivo directamente en el navegador.

## Publicar en Vercel
Importá el repositorio GitHub en Vercel. No hace falta configurar framework ni build command; dejá el proyecto como sitio estático. `index.html` debe permanecer en la raíz.

El formulario usa el número de WhatsApp configurado en el JavaScript de `index.html`.
